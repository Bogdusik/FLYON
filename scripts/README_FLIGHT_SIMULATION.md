# Flight Simulation Script

## Описание

Скрипт `simulate_15min_flight.py` симулирует 15-минутный полет дрона в реальном времени с автоматическим возвратом домой (RTH) при низком заряде батареи.

## Функции

1. **Симуляция полета в реальном времени** - отправка телеметрии каждую секунду в течение 15 минут
2. **Автоматический RTH** - система автоматически определяет, когда нужно вернуться домой на основе:
   - Уровня батареи
   - Дистанции до дома
   - Погодных условий (ветер, температура)
   - Расчетного времени возврата
   - Необходимого заряда батареи для возврата

3. **Умная логика полета**:
   - Дрон летит к заданной точке назначения
   - После достижения цели возвращается домой
   - Автоматически снижается батарея во время полета
   - Система мониторит батарею и предупреждает о необходимости RTH

## Использование

```bash
# Device token берётся из переменной окружения (скопируйте его на странице Drones)
export FLYON_DEVICE_TOKEN=<your-device-token>
python3 scripts/simulate_15min_flight.py

# Или передайте токен аргументом (имеет приоритет над FLYON_DEVICE_TOKEN)
python3 scripts/simulate_15min_flight.py YOUR_DEVICE_TOKEN
```

Без токена скрипт сразу завершится с подсказкой. Подробнее: [docs/USING_DEVICE_TOKEN.md](../docs/USING_DEVICE_TOKEN.md).

**Примечание:** На macOS используйте `python3` вместо `python`.

## Параметры полета

- **Длительность**: 15 минут (900 секунд)
- **Начальная позиция**: 51.505, -0.09 (London)
- **Целевая позиция**: ~1км от старта
- **Скорость**: 12-18 м/с
- **Высота**: 50-80 метров
- **Батарея**: Начинается с 100%, постепенно уменьшается

## Автоматический RTH

Система автоматически проверяет батарею при каждом обновлении телеметрии и:

1. **Расчитывает**:
   - Дистанцию до дома
   - Необходимый заряд батареи для возврата
   - Время возврата
   - Влияние погодных условий (ветер, температура)

2. **Предупреждает** при:
   - Батарея < 30% с низким запасом для возврата
   - Батарея < 15% - критическое предупреждение

3. **Автоматически запускает RTH** при:
   - Батарея < 15% (критический уровень)
   - Недостаточно батареи для безопасного возврата

## Мониторинг

Во время полета вы увидите:
- Время полета
- Фазу полета (OUTBOUND / RETURNING)
- Текущие координаты
- Уровень батареи
- Дистанцию до дома
- Скорость

## Важные замечания

- Скрипт отправляет телеметрию в реальном времени (каждую секунду)
- Система автоматически определяет необходимость RTH
- Все предупреждения и команды RTH отправляются через WebSocket
- Полет можно остановить вручную (Ctrl+C) или он завершится автоматически через 15 минут
